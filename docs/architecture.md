# Arquitetura · v0.1

- Next.js App Router com TypeScript estrito.
- Homepage majoritariamente server-rendered, com componente client isolado para o explorer.
- Conteúdo técnico do workflow centralizado em `lib/inova.ts`.
- Sem backend, autenticação ou consumo de segredos institucionais.
- A arquitetura ilustrada simplifica a execução e não representa sequenciamento rígido dos quatro modelos: GPT-OSS, CLIP, BLIP e NSFW são aplicados em tarefas diferentes, conforme necessidade.
